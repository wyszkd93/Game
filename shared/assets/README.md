# 펭귄 그림 / 3D 모델

## 기본: 시안 그림 (`shared/assets/penguin/`)
두 게임의 펭귄은 `penguin/` 폴더의 그림을 보는 각도에 맞춰 골라 보여줍니다.
파일 이름은 `<색>-<방향>.webp` 이고 색은 `red`·`green`·`blue`·`pink`, 방향은 `front`(정면)·`tq`(3/4, 화면 오른쪽을 봄)·`side`(옆, 화면 왼쪽을 봄)·`back`(후면)입니다.
그림을 바꾸려면 같은 이름·같은 방향 규칙으로 투명 배경 `.webp`를 덮어쓰면 됩니다. 키 약 400px, 발이 이미지 맨 아래에 닿게 잘라 주세요.
주소에 `?penguin=3d` 를 붙이면 그림 대신 아래의 3D 펭귄(도형 또는 `.glb`)이 나옵니다.

---

## 3D 모델(.glb) 넣는 법 (`?penguin=3d` 일 때만 사용)

`shared/assets/penguin.glb` 파일을 이 폴더에 넣으면 눈싸움·낚시 두 게임의 **모든 펭귄**이 그 모델로 바뀝니다.
파일이 없거나 읽지 못하면 기본(도형) 펭귄이 자동으로 쓰입니다. 코드는 `shared/penguin.js`에 있습니다.

## 모델 규격

| 항목 | 규칙 |
| --- | --- |
| 형식 | `.glb` (binary glTF 2.0), 파일명은 정확히 `penguin.glb` |
| 방향 | 앞쪽(얼굴)이 **+Z**를 보게 (glTF 기본). 뒤를 보면 `shared/penguin.js`의 `MODEL_YAW`를 `Math.PI`로 |
| 크기·위치 | 자동 보정됩니다(키 2.3으로 맞추고 발을 땅에 붙임). 대충 서 있는 자세면 됩니다 |
| 용량 | 3MB 이하 권장(시작할 때 한 번 내려받음), 삼각형 수는 1~2만 이하 권장 |
| 모자·목도리 색 | 재질(Material) 이름에 `hat` 또는 `scarf`(`santa`, `cap`도 인식)가 들어 있으면 플레이어가 고른 색으로 칠해집니다. 없으면 색 선택은 모양에 영향이 없고 이름표만 구분됩니다 |
| 애니메이션(선택) | 클립 이름에 `walk`(없으면 첫 클립) 와 `idle`이 있으면 걸을 때/설 때 재생. 클립이 없으면 코드가 뒤뚱거림을 대신 줍니다 |
| 윤곽선 | 코드가 자동으로 검은 외곽선을 붙입니다(모델에 넣을 필요 없음) |

## 그림 → .glb 만드는 순서(제안)

1. Gemini로 만든 정면(또는 3/4) 이미지를 **배경이 단순한 PNG**로 준비
2. 이미지 → 3D 변환 도구로 `.glb` 생성. 도구 후보: Meshy, Tripo, Rodin, Hunyuan3D 등
   — 현재 요금·무료 한도·결과물 상업적 이용 조건은 도구마다 달라서 **직접 약관을 확인**하세요
3. 결과물이 무거우면 줄이기: `npx @gltf-transform/cli optimize in.glb penguin.glb` (옵션은 `--help`로 버전에 맞게 확인)
4. 모자·목도리를 색 변경하고 싶다면 Blender 등에서 그 부분의 재질을 따로 나누고 이름에 `hat`/`scarf`를 넣기
5. `penguin.glb`로 저장해 이 폴더에 넣고, 로컬에서 `http://localhost:8000/christmas/`로 확인

> 이미지 한 장에서 만든 3D 모델은 뒷모습이 어색하거나 표면이 거칠 수 있습니다. 결과가 마음에 안 들면 3D 도구에 정면·측면·후면 이미지를 함께 넣거나 모델을 다듬는 단계가 필요할 수 있습니다.
